**WeatherNow** is a premium, beautifully designed live weather dashboard. It delivers real-time forecasting, air quality tracking, and intelligent clothing recommendations wrapped in a sleek, responsive glassmorphism UI.

## ✨ Key Features

* **🌡️ Live Conditions:** Real-time temperature, "feels like", and precise weather states.
* **📊 24-Hour & 7-Day Forecasts:** Beautifully wrapped hourly predictions with rain probabilities, and an extended 7-day outlook.
* **🍃 Air Quality & Environment:** Live European AQI score, UV Index, and Pollen tracking (Birch & Grass).
* **👕 "What to Wear" Guide:** Smart recommendations on clothing and accessories (e.g., umbrellas, sunglasses) based on temperature, wind, and UV index.
* **🌍 Global Search & Location:** Search for any city worldwide, or use auto-geolocation to get weather for your current spot.
* **⭐ Favourites Bar:** Save and pin your most visited cities for one-click access.
* **🌗 Dark & Light Mode:** A stunning, system-persistent theme toggle.
* **🌐 Bilingual Support:** Fully localized in English and Hindi (`हिन्दी`).
* **📲 Share & Export:** One-click sharing via the native Web Share API and PDF export functionality.
* **⏱️ Auto-Refreshing:** Seamless 15-minute background countdown to keep data perfectly synced.

## 🚀 Built With

* Pure **Vanilla HTML, CSS, & JavaScript** — zero frameworks and blazing fast.
* **[Open-Meteo API](https://open-meteo.com/):** Free, open-source weather and air quality data with no API keys required.
* **CSS Variables & Flexbox/Grid:** For a fluid, 100% responsive layout across all devices.

## 🛠️ Usage

Simply clone the repository and open `index.html` in your browser. No `npm install`, build steps, or API keys required!

```bash
git clone https://github.com/ujjwalraj16/Weather-Now.git
cd Weather-Now
open index.html
```

## 🎨 Design Philosophy

WeatherNow prioritizes **visual excellence** and **user experience**:

* **💎 Premium Aesthetics:** Curated HSL color palettes, modern Inter typography, glassmorphism effects, and subtle gradients.
* **✨ Micro-animations:** Smooth hover states, animated weather icons, and popping UI elements that make the interface feel alive.
* **🧹 Clutter-Free:** The layout intentionally removes horizontal scrollbars and sliders in favor of clean, wrapping grids.
* **📱 Responsive First:** Designed to provide a consistent and polished experience across desktop, tablet, and mobile devices.
* **⚡ Performance Focused:** Built with vanilla technologies to keep the application lightweight, fast, and dependency-free.
